# SpotifySkin

Spotify desktop widget for Windows OS built using Rainmeter, HTML and JS. 
In order to download and use the widget you need to have Rainmeter and Spicetify installed on your machine. 
[Spicetify Download](https://spicetify.app/)
[Rainmeter Download](https://www.rainmeter.net/)
